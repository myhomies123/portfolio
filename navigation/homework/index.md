## What to submit

Open the lesson above and copy its published URL into the teacher's assignment channel. Where a source lesson has a Code Submission form, paste the self-contained Homework code (without Markdown fences) into its code field and put the notebook link, tests, and MCQ result in Notes. Publishing to GitHub does not submit that external form.

MCQ written answers are checked against the supplied lesson keys; classroom participation is evaluated separately. Both older Developing Algorithms and Developing Procedures lessons have exercises but no separate scored homework rubric.
